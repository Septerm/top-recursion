# top-recursion

A Simple project where both a fibonacci and merge sorting function was created as recursive functions as part of [The Odin Project](https://www.theodinproject.com/) JavaScript curriculum. The project also contains several scripts and test for ensuring that they perform as expected.

## Built With

- **Vanilla JavaScript (ES6 modules)** — the app uses modules throughout

- **Jest** - the functions test were carried out using jest

- **Babel** - was use to allow for ES6 modules rather then using require for importing functions

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) and npm installed on your machine.

### Installation

```bash
# Clone the repository
git clone https://github.com/Septerm/top-recursion.git

# Navigate into the project
cd jest-testing

# Install dependencies
npm install

# Running jest test

npm test

```
